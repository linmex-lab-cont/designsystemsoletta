# Soletta — Marketing Website (UI kit)

A high-fidelity recreation of the Soletta landing page for a single development, composed entirely from the design-system primitives.

- **Entry:** `index.html` — interactive: sticky nav fades to solid on scroll, "Contáctame" smooth-scrolls to the form, financing-plan cards are selectable, the contact form shows a success state on submit.
- **Sections:** `sections.jsx` exports `NavBar, Hero, Features, Masterplan, Plans, Contact, Footer`.
- **Composes:** `Logo, Button, Badge, Stat, Card, FeatureBadge` from `window.SolettaDesignSystem_19cf15`.
- **Icons:** Lucide (CDN) — closest match to the brand's line-icon set. See README iconography note.
- **Imagery:** real coastal/terrace photography from `assets/imagery/`.

Content mirrors the brand's real collateral (carta de venta, posts): three financing plans, 35 lots, lots desde $837,760, Pueblo Mágico / Playa Platino credentials, Sisal & Chicxulub.
