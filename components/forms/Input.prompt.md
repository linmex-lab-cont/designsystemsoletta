Single-line text field with an uppercase label, optional left icon, hint and error states.

```jsx
<Input label="Nombre" placeholder="Tu nombre completo" />
<Input label="Correo" type="email" hint="Te contactaremos en 24 h" />
<Input label="Teléfono" error="Número no válido" />
```

- Label is wide-tracked uppercase (brand label motif). Focus ring is marine.
- Pair with `Button variant="accent"` for contact forms.
