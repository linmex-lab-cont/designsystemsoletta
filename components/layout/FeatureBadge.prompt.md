The brand's circular marine icon disc — used for feature rows (plusvalía, escrituración, acceso al mar, distancia a Mérida).

```jsx
<FeatureBadge icon={<TrendingUp/>} />
<FeatureBadge icon={<FileCheck/>} variant="coral" size={56} />
<FeatureBadge icon={<Waves/>} variant="outline-light" />  {/* over photography */}
```

- Pair with a short bold value + caption beneath it. Use line icons with ~1.75px stroke (Lucide) — see README iconography note.
- Keep the icon simple and singular; the disc is a quiet credential, not decoration.
